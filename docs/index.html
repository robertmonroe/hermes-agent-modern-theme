How to install

You only need Hermes Agent installed. No restart and no coding: download one small file, then pick it in the dashboard.

  1. Pick a theme

    Each card above shows the theme's file name, for example modern-slate or modern-blue.

  2. Download it into Hermes

    Open a terminal and paste the commands for your system. They find your Hermes folder for you and save the theme in its dashboard-themes folder. Replace modern-slate (it appears twice) with the theme you picked.

    Windows (PowerShell)
    $dir = Join-Path (Split-Path (hermes config path | Select-Object -Last 1)) "dashboard-themes"
New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://raw.githubusercontent.com/robertmonroe/hermes-agent-modern-theme/main/themes/modern-slate.yaml -OutFile "$dir\modern-slate.yaml"
    macOS / Linux (Terminal)
    dir="$(dirname "$(hermes config path | tail -n 1)")/dashboard-themes"
mkdir -p "$dir"
curl -fsSL https://raw.githubusercontent.com/robertmonroe/hermes-agent-modern-theme/main/themes/modern-slate.yaml -o "$dir/modern-slate.yaml"

    Want more than one? Run the last line again with another name.

  3. Turn it on

    1. Open the dashboard. If it isn't running, start it with hermes dashboard and open the address it prints (usually http://127.0.0.1:9119).
    2. Refresh the page.
    3. At the bottom of the left sidebar, click the theme switcher. It shows the current theme's name, Hermes Teal by default.
    4. Pick your theme, for example Modern Slate.

    Or switch from the terminal: hermes config set dashboard.theme modern-slate

Switch back

Choose Hermes Teal in the theme switcher. To remove a theme, delete its .yaml file from dashboard-themes.

Theme not in the list?

Refresh the page. Still missing: the file belongs in dashboard-themes next to the config.yaml that hermes config path prints.

Chat terminal didn't change?

That's expected. These themes style the dashboard; the chat terminal keeps your Hermes skin. Parts still look old? Hard refresh with Ctrl+Shift+R.
